## Open Social Comments 1.1.0

### New and improved

- Proper threaded replies on Mastodon and Bluesky, with collapsible branches,
  links back to parent comments and readable indentation on small screens.
- Correct hyperlinks on both platforms, including full destinations behind
  shortened URLs, Bluesky mentions and Unicode hashtags.
- Separate platform loading, useful error messages and retry controls.
- Mastodon content warnings and sensitive attachments stay collapsed initially.

### Important fixes

- Fix startup when only Bluesky is configured.
- Sanitize external HTML before inserting it, with DOMPurify bundled locally.
- Stop replacing Quarto's page content, preserving other interactive elements.
- Handle deleted or blocked posts, missing parents, duplicate replies and
  multiple comment components on the same page.

### Install or update

For a new Quarto project:

```sh
quarto add AndreasThinks/quarto-open-social-comments
```

For an existing installation, run this in the project directory:

```sh
quarto update extension AndreasThinks/quarto-open-social-comments
quarto render
```

To pin this exact release:

```sh
quarto add AndreasThinks/quarto-open-social-comments@v1.1.0
```

Existing `mastodon_comments` and `bluesky_comments` YAML settings continue to work.
Quarto >= 1.3.0 is required. No npm installation or build step is needed by users.

The widget displays the public replies returned by each platform; platform API
limits still apply. Posting replies continues on Mastodon or Bluesky.

### Verification

17 browser regression tests and five Quarto integration tests pass. The release
is published only after the repository's automated test workflow succeeds.
